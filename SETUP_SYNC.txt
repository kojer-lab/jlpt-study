JLPT N1 Study v3.1 - PC / Mobile Sync Setup

1. Supabase에서 새 프로젝트를 만듭니다.
2. SQL Editor를 열고 supabase_schema.sql 전체를 실행합니다.
3. Supabase 프로젝트의 Project URL과 Anon/Publishable Key를 확인합니다.
   - service_role 키는 절대 사용하지 마세요.
4. JLPT_N1_Study_v3.1_sync.html을 GitHub Pages에 올릴 때 index.html로 이름을 바꿔도 됩니다.
5. 웹페이지 > PC·모바일 동기화에서 URL/Key를 저장합니다.
6. 이메일/비밀번호로 계정을 만들고 로그인합니다.
   - Supabase 설정에 따라 이메일 확인이 필요할 수 있습니다.
7. 모바일에서도 같은 GitHub Pages 주소를 열고, 같은 URL/Key와 같은 계정으로 로그인합니다.
8. 이후 SRS 평가/문제 풀이/오답 변경은 localStorage에 즉시 저장되고 약 1.4초 뒤 클라우드로 자동 업로드됩니다.

GitHub Pages 간단 배포
- 새 GitHub repository 생성
- HTML 파일을 index.html로 업로드
- Settings > Pages > Deploy from a branch > main / root 선택
- 생성된 https://<계정>.github.io/<repo>/ 주소로 PC와 모바일에서 접속

동기화 충돌 규칙
- SRS: 각 단어에서 더 최근에 학습한 기록을 우선
- 오답: 항목별 최신 내용을 유지하고 틀린 횟수는 큰 값을 우선
- 총 문제/정답 수: 중복 집계를 피하기 위해 큰 값을 우선
- 일반적으로 한 기기에서 공부 후 온라인 상태에서 동기화된 다음 다른 기기를 사용하면 가장 안정적입니다.

보안
- Anon/Publishable Key는 브라우저 앱에서 사용하도록 만든 공개용 키입니다.
- 데이터 접근 제한은 supabase_schema.sql의 RLS가 담당합니다.
- service_role key는 HTML이나 브라우저에 절대 넣지 마세요.
