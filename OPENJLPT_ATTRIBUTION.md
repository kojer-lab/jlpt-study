# OpenJLPT attribution

This project incorporates vocabulary data derived from **OpenJLPT** by Evan Clancy and contributors.

- Source: https://github.com/evanclan/OpenJLPT
- License: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)
- Upstream vocabulary levels are community approximations; the JLPT does not publish official vocabulary lists.
- Imported fields used here include Japanese word forms, readings, JLPT N1 classification, and English glosses.
- This project's curated Korean vocabulary entries remain separate from the imported OpenJLPT dataset.

See the upstream project for source provenance and per-field attribution:
https://github.com/evanclan/OpenJLPT/blob/main/NOTICE.md
