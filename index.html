PC · 모바일 동기화

Supabase에 학습 기록만 저장해서 PC와 모바일에서 같은 SRS·오답 기록을 사용합니다.
미연결
① Supabase 연결
이 키는 Supabase의 공개용 키입니다. service_role 키는 절대 입력하지 마세요. 실제 보호는 아래 SQL의 RLS 정책으로 합니다.
② 같은 계정으로 로그인
PC와 모바일에서 같은 이메일 계정으로 로그인하면 됩니다. Supabase 설정에 따라 가입 후 이메일 확인이 필요할 수 있습니다.
동기화 상태
클라우드 미연결
먼저 Project URL과 공개용 키를 저장하세요.
로그인 계정
-
마지막 동기화
-
일반 사용에서는 자동 동기화가 켜집니다. 두 기기에서 동시에 오프라인으로 공부한 경우에는 SRS 항목별 최근 기록을 우선해 합칩니다. 총 문제 수·정답 수는 중복 집계를 피하기 위해 더 큰 값을 우선합니다.
처음 한 번만 해야 할 일
1. Supabase 프로젝트를 만들고 함께 제공한 supabase_schema.sql을 SQL Editor에서 실행합니다.
2. Project URL과 Anon/Publishable Key를 위에 붙여 넣습니다.
3. 계정을 만든 뒤 PC와 모바일에서 같은 계정으로 로그인합니다.
4. 이후에는 문제를 풀거나 SRS 버튼을 누른 뒤 약 1~2초 내에 자동 업로드됩니다.

통계 · 데이터

기본은 localStorage에 저장하고, 클라우드를 연결하면 Supabase와 자동 동기화합니다.
